# IAM System Test Plan

## Purpose

The purpose of this test plan is to check whether the Sunhaven Care IAM system works correctly and meets the main project requirements.

## Features to Test

1. User account creation
2. Role-Based Access Control (RBAC)
3. Multi-Factor Authentication (MFA)
4. Joiner, Mover and Leaver (JML) process
5. Audit logging
6. Access review

## Test Environment

Testing will be completed using the Microsoft Entra ID test environment created for this project.
Only fictional test users will be used. The test users and roles will follow the final IAM and RBAC configuration used by the project team.

## Evidence

Testing evidence will include:

- Screenshots
- Audit logs
- Test results
- Pass or fail status
- Notes about any problems found

## Pass and Fail

A test will pass when the actual result matches the expected result.
A test will fail when the expected result is not achieved or an error occurs.
