# Sunhaven portal 14.0

Start from the project root with `python run.py`; see the root README and `docs/V14_OPERATING_GUIDE.md`. This folder contains the editable portal source, SQL schema, static frontend, tests, configuration and deployment entry points. Python 3.12+ is required. Local login is a password-free synthetic demo, Graph is mock-only, and external integrations need implementation/acceptance.
